This checks the recorded queue event amounts and the pinned queue state for users identified by those events. Only three of 8,516 harvest events have historical storage-diff coverage. The event census and these samples do not prove that every historical event credited a spendable balance, that any harvest directly delivered Core USDC, or that no unlogged queue writes affected addresses absent from the event history. The [older exact-runtime debt lifecycle](older_exchange_library.md) separately verifies a constructed harvest credit, while the [older withdrawal census](older_withdrawals.md) verifies Core delivery for recorded withdrawals. Neither establishes general redeemability of historical queue payouts.
