## Method and limits

- Static layer: `cast disassemble` of the two pinned runtimes, a dispatcher byte-pattern scan for each entry point, the canonical calldata length constant, the calldata offsets actually read, the caller checks reachable from the entry (slot, comparison site) and every constant that the region touches. The linked library runtime contains zero `CALLER` instructions; its preamble compares `ADDRESS` with its own address, so a direct call reverts with empty data while a delegatecall executes.
- Replay layer: one generated Foundry suite etches the pinned proxy, the Exchange implementation, the linked library, the Oracle, Tokenomics and PAPER runtimes, seeds the pinned storage words that the saved artifacts hold, replaces the 0x080e price address with a two-word mock, and records calldata, revert data, log topics, log sizes and the before/after value of every watched slot.
- This page describes the pinned implementation only. The Exchange proxy's implementation changed after the pin on the live chain; post-pin behaviour is outside this record.
- Observed revert values, with the exact byte evidence in the pinned runtimes: `0x0dc149f0` (AlreadyInitialized(); bytes at exchange offset -1, library offset -1); `0x30cd7471` (NotOwner(); bytes at exchange offset 19054, library offset -1); `0x49199fb6` (NotPauseAuthority(); bytes at exchange offset -1, library offset -1); `0x5b6d2b7a` (library queue-range or merge-limit error; bytes at exchange offset -1, library offset -1); `0x67207a88` (InvalidInstrumentId(); bytes at exchange offset -1, library offset -1); `0x924d25e6` (unnamed; bytes at exchange offset -1, library offset -1); `0x94e88a21` (PositionNotOpen(); bytes at exchange offset 11803, library offset -1); `0x967d697b` (unnamed; bytes at exchange offset 20876, library offset -1); `0xb0cb274d` (instrument field validation error; bytes at exchange offset 4929, library offset -1); `0xcd4e6167` (FeeTooHigh(); bytes at exchange offset 4363, library offset -1); `0xddeb79ba` (NotLiquidatable(); bytes at exchange offset -1, library offset -1).
