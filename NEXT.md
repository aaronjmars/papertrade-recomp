# Papertrade atlas: next work

The goal is a reproducible behavior map of the **entire live Papertrade contract suite** at HyperEVM block 48,902,346. [ATLAS.md](ATLAS.md) is the current report; [unresolved.json](atlas/block_48902346/unresolved.json) and [selector_coverage.md](atlas/block_48902346/selector_coverage.md) are the work queues. The readable pseudocode is reconstructed behavior, not verified Papertrade source or a completed audit. The live suite has since moved to a fourth set, so this pin is the audited baseline rather than the current code; see [Post-refresh set](#post-refresh-set-2026-10-22) below.
